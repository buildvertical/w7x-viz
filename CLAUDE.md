# CLAUDE.md

This file gives instructions to Claude Code (claude.ai/code) for the work in this repository.

## What this repository is

An interactive 3D view of the Wendelstein 7-X plasma boundary, colored by the magnetic field
strength. The viewer is one self-contained page: `index.html` and `w7x_bmod.html` are the same
page. GitHub Pages serves the repository, and `README.md` gives the address.

## Writing

- **Write in Simplified Technical English (ASD-STE100)** in all parts of the system: code (comments,
  docstrings, messages), documents and menus. Try to write a minimum of 80% of the text in STE.
  Write short sentences: a maximum of 20 words in an instruction and 25 words in a description. Give
  one topic in each sentence, and use the same word for the same item. Use the active voice, the
  simple tenses and no semicolon. The specification is free of charge from www.asd-ste100.org.
- **Make a diagram when a diagram is much easier to process, parse and understand than text.**
  Examples are a sequence, a decision and a state machine.
